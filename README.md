## v9（2026-11-25 追加：LPの申し込み・相談をフォーム送信に）
- web.html／student.html／ai.html の申し込み・相談は、メールの下書き（mailto）ではなくフォームから直接送る（`form.js`）。
- 送信は FormSubmit（formsubmit.co、無料・サーバ不要）経由で **itwoshiyou+thebonjin@gmail.com** に届く。Gmail で「宛先: itwoshiyou+thebonjin@gmail.com」のフィルタを作れば振り分けられる。
- 届くメール：件名は「【学割申込】〇〇 さま｜THE BONJIN」のように種別と名前入り。本文は「項目｜内容」の表（種別・入力内容・送信日時・送信元ページ）。返信すると応募者のメールアドレス宛てになる。
- **最初の1回だけ**：初めて送信すると FormSubmit から確認メールが届くので、中の「Activate」を押す。押すまでは応募が届かない。
- フォームの項目は HTML の `name`（日本語）がそのままメールの表の見出しになる。送信に失敗したときは、同じ内容を入れたメールの下書きリンクを出す。
